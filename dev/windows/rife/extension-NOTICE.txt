Tigerest Theater Windows NVIDIA RIFE extension 1.0.0

This extension is an optional component of Tigerest Theater. It does not include
an NVIDIA display driver. NVIDIA TensorRT/CUDA components remain subject to
their respective NVIDIA software license agreements supplied in this directory.
They are distributed unmodified for use with this application.

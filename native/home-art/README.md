四张原创背景均由内置 GPT Image 工具生成（2026-10-09），原始 PNG 为 1536 × 1024。文字由首页按当前服务器的真实媒体库名称绘制；图片不绑定特定服务器、媒体库 ID 或作品。

用途：anime 为动漫类名称，movies 为电影库，series 为其他媒体库，favorites 为收藏。Android 通过 WebViewAssetLoader，桌面通过 Qt 资源加载。

# Tigerest Theater 2.9.1 · Jellyfin 默认主题

本次发布 **Windows 与 Android**，只更新共用网页插件，Windows 运行库、修补版 QtWebEngine 与 Android 原生部分都与 [2.9.0](2026-10-19-v2.9.0.md) 相同。Mac、iPad 与 Apple TV 的 2.9.x 在 Mac 上构建和验证后补充；在此之前它们继续使用 [2.8.0](2026-10-16-v2.8.0.md)。

## Jellyfin 默认主题

- 服务器提供的自定义 CSS 默认禁用，相当于在 Jellyfin「显示」设置里勾选「禁用服务器提供的自定义 CSS」。手机和电脑都按 Jellyfin 默认主题显示，服务器主题不再与客户端的深色顶栏、转场和卡片样式互相冲突。
- 这项设置按服务器账号分别保存。在「显示」设置里取消勾选后，客户端保留你的选择，不会再改回禁用。
- 默认主题下海报圆角外不再露出深色直角（卡片占位层和模糊预览图此前没有跟随圆角）。
- 触屏设备上，首页和媒体库标签栏下方不再出现灰色横向滚动条。

## 修复与改进

- **Jellyfin 详情横幅：** Jellyfin 只在它的手机布局里给详情页顶部填横幅图，而客户端在手机和折叠屏上使用桌面布局，于是顶部留下一块 40vh 的空白。现在在窄屏下按 Jellyfin 手机布局的方式补上作品的横向背景图（单集用剧集背景图，没有横向图时保持原样，不拿竖版海报裁切），遵循「显示」设置里的「详情横幅」开关。
- **海报飞行卡顿：** 新页面显示后，Jellyfin 还会陆续插入剧集、演员、相似推荐和评论区，每一批的样式计算与栅格化都会在手机上卡住合成，飞行中出现 30–60 ms 的长帧。现在飞起的海报会停在上浮状态，等页面停止变化、帧率平稳后再起飞（通常多等 0.2–0.45 秒），模糊层和落点海报的隐藏也提前到遮罩之下完成。小米 MIX Fold 4 实测：飞行中 p95 帧间隔由 25–50 ms 降到 8.4 ms（120 Hz 满帧），最长帧由 50–58 ms 降到约 17 ms。
- **Emby 竖屏单集页：** 宽度不足 50em 时，Emby 把单集的 16:9 截图当作 40vh 高的背景裁切显示，顶部又被不透明的顶栏盖住，人物上半部分看不到；单集自己的主图在这个布局下是隐藏的，从作品详情点单集时海报找不到落点，只能淡出。现在背景图从顶栏下方开始、按 16:9 完整显示，海报飞行落到这张图上，返回时也从它飞回剧集卡片。作品与电影页的顶部图同样完整显示。
- **触屏滚动条：** 客户端的自定义滚动条在触屏上会占用 8 px 宽的滚动条轨道，让 Emby 的详情页内容比屏幕窄一截。触屏设备改回系统的悬浮滚动条；标签栏仍不显示滚动条。
- **触屏首页：** 在 Jellyfin 首页横滑海报轨、媒体库行或主视觉时，Jellyfin 会把它当成切换标签的手势，误切到「我的最爱」。现在只在这些区域外横滑才切换标签，与 Emby 首页的触屏行为一致。
- **Mac 回传的共享修复：** 原生桥更早就绪；客户端菜单与服务器标签在页面切换后仍可点击；没有演员信息的详情页评论区对齐；剧集列表图片的飞入动画；Modern 布局卡片链接走同一套跳转动画；宽屏详情页海报与标题的布局隔离。

## 安装

- `TigerestTheater-2.9.1-x64.exe`：Windows 安装版；或完整解压 `TigerestTheater-2.9.1-x64.zip` 便携版。Windows 2.5.1 及之后可用内置更新，更新前完全退出客户端；便携版保留 `data`。未做 Authenticode 签名。
- `TigerestTheater-2.9.1-android.apk`：Android 15+，沿用原签名，可覆盖升级并保留登录。
- `TigerestTheater-2.9.1-SHA256SUMS.txt` 校验以上文件；`RELEASE-MANIFEST.json` 记录来源提交和验证范围。源码：`client-Sources.zip`、`android-Sources.zip`。
- 修补版 QtWebEngine 组件未改变，仍为 [2.9.0 发行页](https://github.com/Tigerest/Tigerest-Theater/releases/tag/v2.9.0)的 `TigerestWebEngine-6.9.3-d3d11.zip`。
- 已安装的 Windows RIFE 扩展可以继续用于 2.9.1。

## 验证范围

- 最终构建的测试、签名与附件哈希以发行页的 `TigerestTheater-2.9.1-RELEASE-MANIFEST.json` 与 SHA-256 清单为准。

## 已知问题

- 部分 Windows 高刷新率环境下，窗口播放可能持续卡顿、增加输出丢帧，而全屏正常。2.9.1 仍未修复，请先使用全屏播放，见[故障排查](https://github.com/Tigerest/Tigerest-Theater/wiki/Troubleshooting)。
- 真实媒体库中进入媒体库或详情页时，网页主线程仍可能有 70–160 ms 的长任务，表现为一次短暂停顿，后续优化。
- Jellyfin 服务器缺少共同作品身份时，同一作品的两个条目仍可能分开显示；同名的不同作品不会按标题合并。

# Tigerest Theater 2.9.0 更新说明草案

状态：本地实现与修复已交付，尚未发布。Windows 实际播放和 Android 本地构建已验证；Apple 构建和移动/TV 真机仍未验证。实际结果由 [验收记录](../verification/2026-10-19-jellyfin-2.9.0.md) 确认。

## Jellyfin 兼容

本轮目标是在 Windows、Mac、Android、iPad 和 Apple TV 上加入 Jellyfin 服务器兼容，保留现有 Emby 功能。通过自建服务器入口填写 Jellyfin 地址，使用对应服务器账号登录；反向代理带有 `/jellyfin` 等子路径时需要完整保留。

适配包括服务类型识别、鉴权、媒体列表与首页字段、图片与字幕地址、MPV 播放接入、续播及支持平台上的下载。Windows 对 Jellyfin 10.9.11、10.10.7、10.11.0、10.11.11、12.2 的隔离真实服务器完成登录、首页、设置、播放、音轨/字幕、跳转及续播验证；12.2 另覆盖 Modern/Legacy、退出/切服、自动下一集与离线下载播放。Apple TV 原生接口完成静态审查，但没有工具链和真机运行结果；不能把 Windows 兼容名单扩展为全平台认证。

连接方式和能力范围见 [Jellyfin 使用说明](../jellyfin-compatibility.md)。

## 保留首页重复作品修复

2.9.0 基于包含 2.8.1 首页去重修复的代码继续开发：服务器为同一作品提供共同身份时，合并不同 Item Id 对应的首页卡片，并保留最近观看记录和最新入库信息；同名的不同作品不按标题合并。没有共同作品身份时仍按 Item Id 区分，不能把 Jellyfin 缺少该字段的情况表述为重复条目已全部解决。

2.8.1 的历史验证见 [2.8.1 更新说明](2026-10-17-v2.8.1.md)。本轮既有去重回归通过，五版真实 API 检查确认同名不同 ID 作品仍分开显示。

## 服务权限与既有功能

Jellyfin 媒体账号只用于自己的服务器；公共评论使用独立账号。接入 Jellyfin 不会自动取得大河专属社区身份、私人报错、共享绑定写入或一起看权限。Android 不新增离线下载或桌面 RIFE；Apple TV 不新增一起看或 RIFE。

部分 Windows 高刷新率环境下窗口播放掉帧的既有问题不属于本轮修复承诺；如果仍出现，请使用全屏播放并参考 [故障排查](../wiki/Troubleshooting.md)。

# Tigerest Theater 2.9.3 · HDR 与更新提醒

本次发布 **Windows 与 Android**。Windows 运行库与修补版 QtWebEngine 与 [2.9.0](2026-10-19-v2.9.0.md) 相同，Android 的 JNI 原生库也与 2.9.0 相同。Mac、iPad 与 Apple TV 的 2.9.x 在 Mac 上构建和验证后补充；在此之前它们继续使用 [2.8.0](2026-10-16-v2.8.0.md)。

## HDR

- **Windows：** 以前 Windows HDR 关闭时 HDR 片源只能色调映射为 SDR；开启时 Windows 报告的 HDR 校准配置文件又被当成色彩目标，HDR10 片源被渲染成约 416 nits 的 SDR 画面。现在播放 HDR 片源前，如果显示器支持 HDR 而 Windows 没有开启，客户端自动开启系统 HDR（设置「播放 HDR 时自动开启系统 HDR」，默认开启），播放 SDR 片源、空闲约 8 秒或退出时恢复；只恢复客户端自己打开的那一次，异常退出后下次启动也会恢复。系统 HDR 开启时以 HDR10 输出，并按显示器自身的峰值亮度映射。切换显示模式时屏幕会黑一两秒。
- **Android：** 在支持 HDR 的屏幕上，HDR10 与 HLG 视频用 MediaCodec 直接输出，由系统合成 HDR 图层，不再由播放器色调映射成 SDR。文本字幕仍按字幕设置显示；图形字幕和没有 HDR10 基础层的杜比视界继续走色调映射。不支持 HDR 的屏幕保持色调映射，画面和字幕效果更好。
- **Android HDR 提示：** 开始播放时左上角显示几秒输出方式和片源、输出的色彩空间，文字与 Mac、iPad 相同。
- **Android 旋转：** 旋转屏幕不再重新打开视频输出（以前每次旋转都会重启解码器）。部分系统在旋转时会截一张 SDR 画面做动画，屏幕亮度可能闪一下，这是系统的旋转动画所致。

## 更新提醒

- 有新版本时，每次打开软件弹窗一次。检查在后台进行，不拖慢启动；如果你已经开始操作时检查才完成，这次不打扰，结果留到下次打开时立刻显示，同时在后台重新核对。
- 更新窗口提供「从GitHub获取更新」「夸克网盘」「百度网盘」「忽略本次更新」和「稍后」。网盘按钮打开该版本的网盘分享页，适合无法访问 GitHub 时手动下载安装包；「忽略本次更新」直到下一个新版本发布前不再弹窗。
- 在「客户端」设置中关闭「启动时检查更新」后既不检查也不弹窗。

## Windows 卡死报告

- 一份 Windows 报告显示播放 HLS 后 Qt 主线程卡住约 30 秒，卡顿结束时启动计时器又把刚要开始的播放判为失败，原因未能复现。现在主线程停止响应 5 秒时会记录各线程的调用栈；卡住或视频启动超时时，自动向服务器管理员发送「自动故障报告」，附带脱敏诊断日志和正在播放的作品，每次运行最多 3 份，可在客户端设置中关闭。
- 启动计时器到点时会等待原生层迟到的回应，不再把卡顿刚结束时开始的播放判为失败。
- mpv 的流探测恢复为默认的「auto」，只对 MP4 与 Matroska 跳过完整探测。

## 安装

- `TigerestTheater-2.9.3-x64.exe`：Windows 安装版；或完整解压 `TigerestTheater-2.9.3-x64.zip` 便携版。Windows 2.5.1 及之后可用内置更新，更新前完全退出客户端；便携版保留 `data`。未做 Authenticode 签名。
- `TigerestTheater-2.9.3-android.apk`：Android 15+，沿用原签名，可覆盖升级并保留登录。
- `TigerestTheater-2.9.3-SHA256SUMS.txt` 校验以上文件；`RELEASE-MANIFEST.json` 记录来源提交和验证范围。源码：`client-Sources.zip`、`android-Sources.zip`。
- 修补版 QtWebEngine 组件未改变，仍为 [2.9.0 发行页](https://github.com/Tigerest/Tigerest-Theater/releases/tag/v2.9.0)的 `TigerestWebEngine-6.9.3-d3d11.zip`。
- 已安装的 Windows RIFE 扩展可以继续用于 2.9.3。

## 已知问题

- 部分 Windows 高刷新率环境下，窗口播放可能持续卡顿、增加输出丢帧，而全屏正常。2.9.3 仍未修复，请先使用全屏播放，见[故障排查](https://github.com/Tigerest/Tigerest-Theater/wiki/Troubleshooting)。
- 无法访问 GitHub 时，客户端目前也查不到新版本（检查本身走 GitHub）；社区服务器的备用查询会在之后的服务端更新中提供。
- 真实媒体库中进入媒体库或详情页时，网页主线程仍可能有 70–160 ms 的长任务，表现为一次短暂停顿，后续优化。
- Jellyfin 服务器缺少共同作品身份时，同一作品的两个条目仍可能分开显示；同名的不同作品不会按标题合并。

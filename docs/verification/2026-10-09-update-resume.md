# 2.5.1 更新下载与弹幕匹配修复

## 手动更新提示

Windows 用户请注意：2.4.4～2.5.0 的内置更新下载可能中途停止。本次请手动下载 Windows 安装包，关闭客户端后安装；便携版请退出后解压到新的目录，再迁移自己的配置。安装本修复版后，后续更新可继续使用内置下载。

## 行为

- Windows 安装版及便携版随包部署校验过的 OpenSSL 运行库，供 Qt 网络组件使用；应用更新与 RIFE 扩展包下载共用该后端。
- 桌面与 Android 更新下载使用稳定摘要标识的缓存，支持暂停、退出后继续；桌面使用强 ETag、Range 和 If-Range，Android 使用严格 Range 并在完成及安装前验证摘要和 APK 身份。
- 中断后按 2／5／10／20／30 秒等待重试。连续没有超过此前最大下载进度时最多重试五次；真正新增进度会重置预算。服务器重复返回同一片段或忽略 Range，不会误判为新增进度。
- 桌面移除固定 30 分钟总下载时限；保留 30 秒无数据传输超时。慢速但持续下载不受总时限限制。
- 暂停或退出后保留下载片段，重新打开并检查更新后可继续下载。
- 每次重试从原始发行地址重新获取临时下载地址。续传范围、文件标识或长度不一致时不拼接数据；服务端返回完整文件时从头替换。
- 完成后验证长度与 SHA-256，安装前再次验证。受损文件不进入安装流程。
- 界面显示已下载大小、速度、暂停、继续和重试次数。
- 桌面和 Android 弹幕自动匹配不再使用日期确认、筛选或排序。先匹配作品及季度；规范化后的集标题唯一对应时优先使用标题，否则按集数匹配。多个等价候选仍由用户手动选择，片头／片尾曲不作为正片候选。

## 验证记录

修复前：Windows 正式安装包 Qt 6.9.3 + Schannel 实际下载多次中断；相同 Qt 网络 DLL 与更新器源码使用 OpenSSL 时两次完整下载并校验 v2.5.0 安装包（243957378 字节）。HTTP/1.1、取消缓冲区上限未解决原故障；不能将底层根因归结为某一项未经证实的 Qt 或系统缺陷。

新增验证覆盖进程退出后续传、错误范围、ETag 变化、服务端忽略 Range、摘要错误、重试上限、多进程写锁和完成包复用。真实 HTTPS 本地夹具与公网附件下载分开记录；本任务不以下载测试替代媒体播放验证。

### 前一轮实际公网下载

- 更新包：两个独立原生进程使用包内 Qt / OpenSSL 3.5.9；清除开发环境 PATH 和 Qt 插件目录覆盖。第一次在 8,893,878 字节暂停，第二次实际发送 `Range: bytes=8893878-` 和相同强 ETag 的 `If-Range`，最终下载 243,957,378 字节。完成状态为 `ready`，SHA-256 为 `920c4d364d551cbbfd8cc55c9c2e2816f5393e43b6cb9e94ef5140a2e9d2de52`，与 v2.5.0 正式安装包一致。测试不启动安装器。
- RIFE 扩展：本地 HTTPS 夹具 10 项通过后，再以实际公开扩展包 URL 在两个独立进程中下载。第一次在 5,325,952 字节取消，第二次增长到 10,566,722 字节；强 ETag 与原片段 SHA-256 保持一致，103 次大小采样未发现归零。测试 helper 需要临时别名 ID，实际 URL、摘要、文件大小和 2.5.1 兼容性保持不变。公网测试没有直接抓取 Range 头，也没有下载完整 2.146 GB 扩展、安装或激活模型；完整校验和异常协议分支由本地夹具验证。

上述公网记录验证 Windows TLS 后端与跨进程续传，不代替本轮重试策略、Android 或弹幕规则的回归结果。

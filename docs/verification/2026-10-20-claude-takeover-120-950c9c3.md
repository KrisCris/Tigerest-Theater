# Claude 接手：媒体库转场 120 帧、退出播放与试用版部署（07722dc–950c9c3）

2026-10-20 03:40–06:10 JST，Claude 接手 Codex 交接（78e5e0c／产品 284ba06）。以下均为实测；夹具、真实远程 API、真机播放、呈现帧和部署分别列出。

## 产品提交

1. `07722dc` 媒体库入场前，在不透明遮罩下等视图加载完再复制入场画面。
   - 等待条件：Jellyfin 加载转圈消失，且节点数连续稳定；上限 2.4 s。
   - 根因：旧实现约 100 ms 就复制，此时页面只有 78 个节点、0 张卡、转圈仍在，入场时卡片才在主线程排版。真实远程诊断中，150 ms 后已有 45 张卡、1166 个节点。
2. `4680916` 入场副本先在遮罩下预绘制。
   - 以最终尺寸、0.01 不透明度、`will-change` 画 3 帧，再播放原来的 460 ms 入场动画。
   - 根因：手机入场开头的长帧来自整页副本首次栅格化和解码。
3. `950c9c3` 复制前还要等目标页视口内没有 `[data-src]`，即 Jellyfin 懒加载已设好封面。
   - 根因：真实 10.11 远程冷启动时，复制那一刻 12 张可见卡片都是 `data-src` + `lazy-hidden`，副本里没有封面，遮罩撤掉后封面才突然出现。
   - 热进入时，复制那一刻封面的 fadein 仍在进行。

测试提交：
- `769195d`：评论分页夹具改为在计时器之后再等两帧（284ba06 改用 rAF 对齐后，Qt 下该测试轮流偶发失败）。

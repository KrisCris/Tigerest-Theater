# 首页媒体画廊验证记录

## 最终行为

替换 Emby 原 `home/hometab.js` 控制器，保留 HomeView、作品详情、媒体库和收藏页原有控制器。首页隐藏原顶栏和侧栏；离开首页恢复原导航。大河服务器使用前三个可访问媒体库和收藏，其他服务器使用全部可访问媒体库及收藏。媒体数据、作品链接和图片始终来自当前登录用户的 ApiClient。

三种可切换构图：沉浸影院（fanart / 竖版封面）、锋芒舞台（fanart / 横版缩略图）、光影画廊（竖版主海报 / 横版缩略图）。风格偏好本地保存。四张分类背景由 GPT Image 生成，提示词和来源记录在 `native/home-art/README.md`。

左侧悬停预览、点击进入媒体库；大图和底部封面点击进入作品页。剧集按最新单集的 DateCreated 排序、每部作品仅一张卡片；电影按自身 DateCreated 排序。分页不截断于第 400 个单集；收藏完整分页后再按最新单集排序。账户切换、暂停或销毁取消请求和轮播。

启动后首次进入首页、或退出登录后重新登录，调用原生窗口接口自动全屏。按服务器和用户记录当前登录会话，从详情／媒体库返回不再强制全屏。异步请求跨注销时由 epoch 防止旧请求污染新会话。

两组飞入动画完成后主海报淡入；窄屏、横屏、键盘聚焦和减少动态效果偏好均有兼容处理。聚焦时结束入场动画并将对应卡片滚入可见范围。

## Windows

- 原生构建及部署暂存包成功。
- 每次原生测试均在同一 PowerShell 调用中读取并加载 `dev/windows/Enter-TestEnvironment.ps1`；预检 MPV、RIFE、Qt、windows/offscreen 插件。
- 最终 `test_home_data`、`test_home_gallery_webengine`、`test_systemcomponent`：3/3 通过。
- 本批此前的首页、消息、报错、设置、启动和登录相关 CTest：12/12 通过；最后收藏兼容改动后只重复受影响的上述 3 项。
- 共享数据和控制器注册测试：17/17 通过，含单集／收藏多页排序、图片类型、当前身份、旧异步请求、原模板 scroller 生命周期、首次全屏和注销竞态。
- QtWebEngine 集成 fixture 验证 QRC 分类插画、布局、飞入顺序、切换、重试、聚焦滚动、暂停／销毁和减少动态效果。该动画 fixture 使用可见硬件加速窗口，隐藏软件窗口没有合成帧，不能据此判断产品动画失败。
- 使用独立已认证预览配置连接真实服务器：原 HomeTab 替换成功，首次首页自动全屏，原导航隐藏，4 个入口及 24 部作品正确加载。
- 真实页面验证：大图／封面到作品详情、媒体库到原浏览页、收藏到原收藏页、原首页按钮／页签到新首页，返回时保留已切换的窗口状态。
- 发现当前 Emby 的 `showFavorites()` 生成 `/home&tab=favorites` 并丢失参数；新首页通过原 `maintabsmanager.selectedTabIndex(1)` 切换原收藏控制器。相关测试在修复前失败、修复后通过，真实收藏页再次验证成功。
- 三版截图来自同一部真实作品。Cinema 和 Pulse 的主图实际为 Backdrop；Gallery 为 Primary；底部为 Primary 或 Thumb。

## Android 和 macOS

Android 与桌面注入相同的首页数据和组件脚本；四张分类插画通过 WebViewAssetLoader 打包。最终 APK 内三个相关 JS 和四张 PNG 的 SHA256 均与源码一致。

Android `assembleDebug` 成功；65 个单元测试、lint 成功（0 错误、37 个既有警告）。此前实机独立调试版已验证原初始风格移动布局和分类插画；最后三版实机检查因设备再次锁屏未完成，不能宣称最新 APK 的完整实机界面验证通过。

macOS 共享原生注入和 JS 已覆盖，本批没有生成或验证新的 macOS 二进制。

# 首页媒体画廊验证记录

## 最终行为

替换 Emby 原 `home/hometab.js` 控制器，保留 HomeView、作品详情、媒体库和收藏页原有控制器。首页隐藏原顶栏和侧栏；离开首页恢复原导航。大河服务器使用前三个可访问媒体库和收藏，其他服务器使用全部可访问媒体库及收藏。媒体数据、作品链接和图片始终来自当前登录用户的 ApiClient。

实机发现原底部导航的类名为小写 `.appfooter`，补齐首页隐藏规则；媒体库中恢复原底栏，返回首页再次隐藏。更新后的调试 APK 已通过 ADB 覆盖安装。

用户从初版三种构图中选定沉浸影院（fanart / 竖版封面）。最终客户端固定采用版 1，移除比较按钮和其余构图，并清除旧风格偏好。四张分类背景由 GPT Image 生成，提示词和来源记录在 `native/home-art/README.md`。

左侧悬停预览、点击进入媒体库；大图和底部封面点击进入作品页。剧集按最新单集的 DateCreated 排序、每部作品仅一张卡片；电影按自身 DateCreated 排序。分页不截断于第 400 个单集；收藏完整分页后再按最新单集排序。账户切换、暂停或销毁取消请求和轮播。

启动后首次进入首页、或退出登录后重新登录，调用原生窗口接口自动全屏。按服务器和用户记录当前登录会话，从详情／媒体库返回不再强制全屏。异步请求跨注销时由 epoch 防止旧请求污染新会话。

两组飞入动画完成后主海报淡入。最终动画将左列从窗口上方移入，包含旋转、过冲和卡片错峰；底部列表从右侧冲入并反弹。图像层独立缩放淡入，标题、元数据、入口和简介依次出现，每次切换作品重新播放文字动画。

简介读取当前作品的 Overview：剧集使用 Series 简介，元数据加载失败不以单集剧情替代。HTML 标记去除并以纯文本显示；桌面放在右下方，窄屏放在标题下方，无简介时隐藏。图片加载卡住仍能显示文字；切换作品先淡出旧图并替换背景节点，避免旧图长期配上新文字。矮手机布局的最低高度与网格总高度一致，可通过原 scroller 查看完整封面列；短屏文字使用紧凑排版。

窄屏、横屏、键盘聚焦和减少动态效果偏好均有兼容处理。聚焦时结束入场动画并将对应卡片滚入可见范围。

## Android 和 macOS

Android 与桌面注入相同的首页数据和组件脚本；四张分类插画通过 WebViewAssetLoader 打包。最终 APK 内三个相关 JS 和四张 PNG 的 SHA256 均与源码一致。

Android 最终 `assembleDebug` 成功；65 个单元测试、lint 成功（0 错误、37 个既有警告）。此前实机独立调试版已验证原初始风格移动布局和分类插画；后续实机检查因设备再次锁屏未完成，不能宣称最终 APK 的完整实机界面验证通过。

后续手机解锁并登录后，在真实服务器的折叠机内屏纵向窗口（760×850 CSS 像素）验证版 1、四个入口、24 部作品、海报、简介和分类插画；无网页加载错误。补齐底栏规则后，安装最新 APK 再验证“首页隐藏 → 媒体库恢复 → 返回首页隐藏”成功。外屏及其余旋转模式尚未在最终包上重新实测。

一次预览启动失败来自先前实机夹具留下的 `http://127.0.0.1:12733` 地址，错误为 `ERR_CONNECTION_REFUSED`，不是首页脚本失败。通过应用连接页恢复真实服务器地址并核对其保存值；用户登录后加载成功。Android 测试说明已加入交付预览前的地址核对要求。

macOS 共享原生注入和 JS 已覆盖，本批没有生成或验证新的 macOS 二进制。

# Jellyfin 2.9.0：Apple 120 帧与退出播放追加验收

更新时间：2026-10-20 01:11 JST。此文补充已发送的 6fe1b3d 累计增量及 Apple 独立工作，不代表新性能实现已完成。

## 用户明确要求

Android、PC 的动画和滚动都按持续 120 帧验收，Apple 同步遵守这项交互目标。保留现有动画、返回逻辑、视觉层次和配置；不得以关闭动画、降低刷新率、缩小测试分辨率或静态页面的 rAF 数字宣称达标。用户同时报告 PC 花屏/撕裂、转场闪烁和 Android Jellyfin 手动退出误续播。

- Windows 侧后续固定候选为 `bbfae89ce345a8f0703118fcfa2133f6d19f7f02`：包含 Jellyfin 取消续集修复、首页控件响应式、Emby 重复设置入口处理，以及两项图像缓存回归修复。尚未作为最终新 Mac 包交付。

## 可以立即并行做的工作

1. 固定本地源码 SHA、编译产物和测试设备；记录设备型号、系统、窗口/视口尺寸、DPR、实际刷新率、节能状态。未有 120Hz Apple 设备时如实标记该部分未测，其他功能检查继续。
2. 对真实 Jellyfin 和 Emby 分别记录：首页进入媒体夹（冷/热）、海报进入详情、详情返回媒体夹、季/单集进出、连续滚动/惯性滚动/图片懒加载。记录实际路由和滚动位移，不能把未发生滚动的采样计为成功。
3. 以约 8.333ms 为 120Hz 的帧预算，输出 P50/P95/P99、最长间隔、错过刷新时机的比例、最长连续掉帧，以及系统呈现帧/合成证据。计时精度误差与真正跨过一个刷新周期应分开。平均 FPS、P95 单值或主线程空闲不能独立证明达标。
4. 无 Profiler 的真实操作测量作为验收；CPU/GPU 分析和抓图分别运行作为诊断，记录工具开销。将网络等待、图像首次加载、动画开始延迟和动画期间掉帧分开报告。
5. Apple 用适合平台的系统性能工具检查呈现、光栅化、图层合成。录屏可能改变刷新率/负载，注明实际限制；页面截图也不能替代最终原生窗口的闪烁/撕裂检查。
6. 在同一场景内多轮复测，并以修复前/后相同页面、尺寸、设备模式作对照。临时 CSS 层开关只用于归因，结束必须恢复，不作为产品交付。

## 特别检查共享动画实现

关注全屏背景的两个 blur(58px) 层、顶栏与子按钮的多层 backdrop-filter、进入动画的 filter/clip-path、frozen 页面复制的布局与样式解析、图片 decode/cache/取消时序。它们是待测对象，不是已证明的统一根因。

Windows 已发现新图像 fetch 路径可能增加点击到转场的准备延迟，Claude 正在验证修正。不要为规避解码成本在点击关键路径上引入新的网络等待。图像取消应传递 AbortSignal，取消后不再 fallback/decode；hover/focus 上移进入视口的边缘卡片不能被父级裁剪误丢弃。采用预制位图/图层复用时保留视觉、尺寸、失效和内存清理语义；原生快照也需要测量，不能先承诺零开销或必达 120。

## Jellyfin 播放退出契约

手动取消与自然结束必须区分。共享 MPV 插件对注入的 Jellyfin playbackManager 在 canceled 的 stopped 事件前调用 declineNextItem，并清理本地续集标志；Emby AMD 路径保持自身协议。Apple 原生桥必须正确发出 canceled/finished/stopped 的实际语义。

Apple 待测：播放器返回、系统返回/关闭、连续返回、加载下一集期间返回、播放错误后退出；这些都不应误续播。自然 EOF 且开启续集时必须仍进入下一集，禁用续集时停住。记录事件顺序、当前媒体 ID 的脱敏映射、原生画面/播放进度；仅 API 成功或页面跳转不算实播。

## Windows/Android 当前已知结果（只作对照）

- bbfa Android 实际 120Hz、847×948 CSS 像素、DPR 2.625：真实连续滚动 P95 约 16.8ms、P99 约 33.3ms；媒体夹冷转场 P95 49.8ms。未达标。
- Android FrameTimeline 的呈现间隔 P95 约 16.667ms，有 AppDeadlineMissed/BufferStuffing。原始 trace 含操作前后闲置，统计还需按活跃区间裁剪；不能拿闲置间隔当最大卡顿。[FrameTimeline 官方说明](https://perfetto.dev/docs/data-sources/frametimeline)
- Windows 硬件加速隔离实例的真实远程转场 P95 约 24–46ms；显示模式与最终原生画面另行核对。不能声称已达 120 或已排除花屏。
- Android 的系统返回和播放器返回已验证能停住；本地真实 Jellyfin 10.11.11 的生成测试片自然结束后第二集实际渲染，随后按返回也停住。该结果不等于 Apple 通过。

# 自动弹幕匹配与 ede.js 评估

## 后续修订：桌面取消日期确认

2026-10-09 18:38 播放《转生成为魔剑了》S02E02 时，客户端元数据的集号为 2，但首播日期为 2026-10-15。弹幕目录中第 2 集 177890002 的日期为 2026-10-08，第 3 集 177890003 的日期为 2026-10-15。旧桌面匹配器将唯一的精确日期候选直接选中，覆盖了集号，实际请求第 3 集弹幕。

随后发布的 2.5.1 主分支已同时取消桌面和 Android 的日期判断，先确认作品与季度，再使用唯一的单集标题或集号。Mac 合并时保留该策略，并补齐作品名中的“第二期”“第2期”季度标记；否则更严格的季度保护会漏掉真实目录里的“转生成为魔剑 第二期”。没有真实文件哈希的 Emby 流媒体统一查作品目录，不再以日期是否有效决定匹配路径。共享接口及保存行为不变。

Mac 回归夹具使用真实第一季及第二期目录名称，覆盖本次 S02E02 案例及缺失、无效、冲突或相差多年的日期，确认只查询第二季并加载 177890002。季度中文数字和阿拉伯数字“期”写法、不同季度冲突均有覆盖。原生 libmpv 测试先复现漏匹配，加入季度别名后通过；该夹具验证不代表真实视频播放验收。打包与发布记录见本次 Mac 验证报告。

## 本次失败的证据

报错附件记录 2026-10-09 02:37:29 自动匹配失败，随后同一搜索词手动选择第 1 集于 02:37:41 加载 735 条弹幕。只读查询生产 NAS API 确认作品 19310 的第 1 集为 193100001，“第1话 开始与结束”。作品和集数均可以识别。

Emby 首播时间是 `2026-01-08T16:00:00Z`，上游日期是 `2026-01-09T00:00:00`。相差一天原本允许走一周内的匹配，但作品目录另有 `C1 Opening`、`C2 Ending`。旧代码将这两个非正片编号视为不完整数据，对整个候选列表设置否决标志，造成漏匹配。

## 用户确认的新取舍

优先得到可用的自动识别结果，允许少量错误，通过 OSD 展示结果和手动纠正来恢复。共享纠正规则优先于自动检索，只有明确的手动选择才写入共享规则。

用户随后要求完全取消日期确认。桌面和 Android 现在先确认作品与季度，再优先采用唯一的规范化单集标题匹配；标题相同可将连续集号 E25 对应到该季度的 E1。标题缺失或译名不同则按集数匹配。首播日期、上游播出日期、日期差和同日发行均不参与筛选或排序。作品相似度至少为 0.85，后续季度必须有对应季度的明确标记；片头、片尾、主题曲及音乐视频条目排除。相同来源、作品和单集 ID 的重复记录去重，同等作品证据下的不同提供方或发行版本、重复标题与重复集数仍需手动选择。

OSD 保留作品名、单集名称和条数，显示五秒并提示从弹幕菜单手动纠正。匹配日志记录标题/集数候选、排除的片头片尾数量，以及是否通过单集标题选中，不再记录日期距离。

## ede.js 中可参考的部分

所提供的 `ede.js` 是 Emby Danmaku Extension 1.47。

- `searchEpisodes` 将哈希匹配、带集数搜索、不带集数搜索、缓存与原标题检索串联，能提高检索覆盖率。后续可以在现有 NAS 接口支持的范围内增加原标题作为备用检索词。
- 从 Emby 的 SeriesName、ParentIndexNumber、IndexNumber 构造作品和集数，使用同一作品/季的校准偏移。这与当前使用原视频 source、手动选择真实 episodeId 后保存共享规则的方向一致。
- 将手动选择结果缓存、允许用户检查和修正自动结果，符合本次要求。

不应直接整份替换当前播放器。脚本有在部分路径取第一个作品结果的行为，哈希失败时使用占位假哈希，某些旧回退调用未传 prefix；`tmdbAutoFailback` 还引用未定义的变量，实际没有使用 tmdbId。它的主要新版流程使用 `/search/episodes`，当前 NAS 托管路径是否提供这个接口需要另行核对。上述备用检索方案属于评估建议，本次没有新增第三方代理或这些接口调用。

## 验证范围

原失败由包含真实 C1/C2 条目的回归夹具复现，修复后通过。取消日期后的回归覆盖日期缺失、无效或相差多年时仍匹配，标题优先映射集号，译名不同时按集数匹配，重复标题/集数的歧义，季度和作品保护，重复记录去重，非正片排除，失败/超时的其他查询、OSD 内容和换片取消。作品名本身包含“第二季”时，先提取作品与季度，支持同季度中文/英文写法以及 11th／12th／21st／23rd 等多位序号；查询标题、元数据或候选季度冲突，以及仅季度相同但作品不同的候选，仍需手动匹配。桌面原生 libmpv 测试通过 6 项 Qt 测试，其运行时夹具包含 66 个行为用例；Android 匹配测试包含 23 项，最终单元、lint 和构建结果见本次发行验证记录。

取消日期前，曾使用真实元数据运行原生 libmpv 中的 Lua 匹配器，匿名读取生产作品目录、单集目录及弹幕接口，自动选中 193100001“第1话 开始与结束”并取得 735 条弹幕。该历史验证使用暂停的合成音频维持异步请求环境，没有播放用户的真实视频，也没有向生产共享规则或报错接口写入数据；不能代替当前规则的生产接口或真实视频验证。报错上传的生产行为来自用户本次提交的实际附件，不把夹具提交当作生产验证。

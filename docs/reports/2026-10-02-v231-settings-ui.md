# V2.3.1 设置与界面验收

本次处理 V2.3 正式版发布后反馈的设置按钮、文件浏览、选集交互和外观问题，并将 MPV 设置整合进 Emby 客户端设置页。

## 修复依据

- NVIDIA 1.0.0 封存扩展的 `maxAppVersion=2.3.0` 是不包含上限的范围，原目录因此排除了正式版。目录增加明确批准的 `2.3.0`、`2.3.1`，保持原 ZIP、文件哈希、运行库身份和 ABI 不变；其他未批准版本继续拒绝。
- Windows QtWebEngine 动态加载的文件选择器依赖 `QtQuick.Dialogs`。显式导入后，部署工具会将所需 QML 模块与插件一并打包。
- Emby 设置插件注册客户端设置路由，使用 Emby 的菜单、页面模板、标题与设置侧栏，复用现有原生配置存储。当前项在侧栏中高亮。暂停页面时取消挂载并清理计时器和信号连接；恢复默认值过程中离开页面也不会留下旧界面。
- 卡片上移由鼠标留下的普通焦点触发，改为鼠标悬停及键盘可见焦点反馈。仅移除封面中央的播放浮层，详情页播放入口继续保留。
- Emby `.scrollY` 与主题样式会覆盖通用滚动条规则；非 `auto` 的标准 `scrollbar-color` 还会让 Chromium 忽略自定义伪元素绘制。客户端增加限定作用范围的样式，保持隐藏横向列表的规则，实际页面使用 9 px 细圆角滚动条。
- Windows 通过 DWM 设置原生深色标题栏及配色，保留系统边框、拖动、最大化和窗口操作。

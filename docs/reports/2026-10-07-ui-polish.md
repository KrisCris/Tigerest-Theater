# 2.4.3 界面与 Android 播放候选版验收

状态：试用候选版，未发布新的 Release，等待用户试用确认后统一发布。公开版本仍为 2.4.2。

## 实现范围

- Android 网页移除多层安全区叠加，内容与顶栏分别避让挖孔；首页、详情和评论使用一致的侧边距。窄屏顶栏按实际高度排列。
- 打开媒体、等待首帧和缓冲时显示加载转圈。空白画面长按临时至少 2 倍速，松手、取消、暂停、音频焦点丢失、后台、停止或换片恢复原速；原本 3 倍速不会被降到 2 倍速。教程补充长按操作。
- 三端评论区位于演职人员上方，标题与页面内容左对齐。每页 10 条主评论，附属回复跟随主评论，支持前后翻页、切换讨论范围和消息定位。
- 设置使用 Emby 分类表单布局，保留搜索、重置、即时保存及平台支持的配置项；窄屏改为横向分类。
- 更新入口位于右上角，有当前平台可安装的新正式版时显示红点。自动检查不弹窗，点击查看详情并下载。

## Android 稳定性修复

真实设备在无效媒体地址返回 HTTP 404 后发生原生 fdsan 崩溃。日志显示 mpv 的 ytdl 回退依次尝试启动未随 APK 提供的 yt-dlp、yt-dlp_x86 和 youtube-dl。Android 客户端接收 Emby 直链，因此初始化时关闭 ytdl 回退，保留原硬解与渲染配置。

另将播放变更与 Surface、播放器事件、手势统一到主线程；桥接回复仍排入消息队列，保证停止信号先于 stop Promise 完成。显示/隐藏回调检查会话代数，避免旧会话影响新画面。

修复后连续三轮完整播放反馈测试通过；最终回归额外重复五次失败地址，进程未退出。该测试覆盖的是受控媒体和失败响应，不代表所有生产媒体格式均已验证。

- 完整 CTest 共 58 项，首次 55 项通过；三项 UI fixture 因隐藏窗口动画调度、初始化覆盖 mock、缺少 UTF-8 声明失败。修正 fixture 后这三项全部通过。
- 更新、设置、Android 内容安全区三项最终 Qt WebEngine 回归 3/3 通过。评论 fixture 按实际 Emby DOM 修正后另行复测 1/1 通过。

- 所有原生测试遵守 `dev/windows/TESTING.md`，同一 PowerShell 调用先加载测试环境；使用隔离配置，未改动已安装播放器设置。

## Android 验证

设备：小米 MIX Fold，Android 16 / API 36；APK 最低 API 35，目标 API 36。

- JVM 43 项通过，0 失败、0 错误；新增加载状态 4 项、临时倍速 3 项。
- lint 0 错误、36 警告。原生库 16 KB 对齐检查通过，Release APK 签名验证通过。
- 真机加载转圈、暂停首帧、失败清理、加载中停止、长按释放/取消、后台恢复、换片恢复、停止事件顺序、原有高倍速保持均通过。
- 手势教程、双击、滑动跳转、音量、亮度、停止清理通过；设置 44 行及保存/重启/重置通过；隔离评论接口 38 次请求通过；首导航桥接及 Android 样式通过。
- 真机强制切换内外物理显示器（2224×2488 / 1080×2520）后，窗口指标、路由、草稿、进程与播放状态检查通过。横竖屏、模拟手机/平板边界通过；模拟边界不等同于真实分屏操作。
- 实际 Android WebView 的 14 项评论分页场景全部通过，含真实 Emby 容器结构和 Android CSS。
- 签名候选版已覆盖安装到正式包名 `top.tigerest.theater`，versionName 2.4.3 / versionCode 2040300；保留原登录状态。实际生产服务器首页、详情、评论位于演职人员上方及新版设置页已在内屏截图核验，未写入测试评论。
- 外屏切换后曾被系统锁屏/AOD遮挡；解锁并完成系统“上滑继续使用”后，已额外核验正式包外屏首页、设置页横向/竖向布局。截图为 `preview-home-outer.png`、`preview-settings-outer-portrait.png`。最终恢复原自动旋转和物理屏幕选择。仍需用户手动折叠及分屏使用验收。
- 正式签名包另在生产 Emby 服务器播放一段 1080p HEVC / AAC / SRT 内容：实际加载转圈、视频及字幕显示、长按 2 倍速提示、松手恢复 1 倍速和双击暂停均经截图确认，随后停止播放。该次短片段验证不等同于整集稳定性或全部编码覆盖。

主要日志：`android/test-artifacts/player-feedback-verified.log`、`player-direct-media-1.log` 至 `-3.log`、`gestures-polish-final.log`、`polish-test_windows.log`、`polish-test_settings.log`、`polish-test_comments.log`、`polish-test_navigation.log`、`polish-pagination-final.log`、`polish-lint-final.log`。

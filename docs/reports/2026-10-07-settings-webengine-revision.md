# 2.4.3 试用修订：Windows 同步运行库与原生设置子菜单

本次修订不创建正式标签或 Release；等待用户实际试用确认。

## Windows 闪烁回退原因

上一份 2.4.3 Windows 试用包的构建缓存中 `TIGEREST_WEBENGINE_RUNTIME` 为空，打包逻辑静默跳过自定义 QtWebEngine。该包带入原版核心 DLL，未带入已验证的 D3D11 producer 同步补丁。已安装日常版仍有正确补丁，未修改日常版程序或配置。

修订后 Windows 配置及安装均强制验证补丁运行库，检查 Qt 版本、伴随文件、资源目录、源码补丁及核心 DLL SHA256。部署在 windeployqt 之后强制覆盖，再核对实际核心 DLL，避免空缓存和旧文件时间戳导致回退。

本次部署的核心 DLL SHA256：`9d410e8aa09e04dcafe759dd4446895011976ad4577e7d7b1977ee8cc156902b`。

## 设置导航

客户端、音频、视频、字幕、MPV 画质与插件、弹幕样式、高级注册为 Emby 原生分类路由，直接列在左侧“Tigerest Theater 设置”分组内。根据用户试用反馈，移除冗余的“MPV 播放设置”父入口；安卓对应移除冗余“客户端设置”父入口，仅保留平台支持的分类。分类使用 Emby 原生图标字体及对齐方式。内容区不再包含第二列分类导航；窄屏由 Emby 原有抽屉访问。右侧搜索限定当前分类，保留即时保存、重置、返回和路由恢复。尚未加载服务器的独立设置入口保留紧凑下拉选择器。

## 半整数 RIFE 倍率

Windows 目标帧率选择改为 1.5–15 倍、每 0.5 倍一档，距离相同取较低档。24 fps 设为 60 输出 2.5×；24000/1001 设为 60 输出 60000/1001。目标 0 仍为 2×。Mac 的固定 2× 后端不改变。

推理按目标时间点采样，避免先生成更高帧率再丢帧。末帧必要时缩短，保留原片总时长；双源帧分组避免高倍率时溢出 mpv 虚拟帧数。Monitor 使用有理倍率并保留旧整数参数兼容。

- 原生新增用例先出现 4/4 预期失败，修复后倍率策略、运行时、Monitor、统计与旧 controller 共 6/6 通过。
- 真实 VapourSynth/TensorRT 图测试 25/25 通过：包含 1.5/2.5/3.5/7.5× 时间点、整数回归、NTSC 时长、单帧/奇数帧数、14.5× 虚拟长度、场景切换、未知元数据和 VFR。FP16 跨推理上下文误差采用 1/2048 上限，原帧仍逐字节比较；相邻错误时间点另有差异断言。
- 实际打包 libmpv + TensorRT 通过 12 组短片流式测试，包含 1～3 帧分别使用 1.5/2.5/3.5×；输出数量、合成帧标记、总时长、末帧时长、Monitor 计数一致。
- 实际 Player 的 30→75 fps（2.5×）缓存播放、暂停、拖动、速度变化、重载和故障恢复通过。该项采用 null 输出，不能代替可见渲染检查。

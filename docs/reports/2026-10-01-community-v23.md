# V2.3 评论区客户端验收

## 范围

公开客户端接入已部署的私有评论服务，复用 HTTP18443。固定大河 Emby 身份与局域网／域名路由，电影、剧集和季使用作品话题，单集提供本集／作品两个入口。协议见 [community-api.md](../community-api.md)。服务端源码、数据库和部署文件没有引入客户端仓库。

## 实现

- 独立请求层负责认证头、Item 上下文、超时、页面／账号取消、幂等提交、限流冷却及认证头像。凭证不放入 URL，错误不转发服务端原始消息。
- 详情 UI 使用纯文本 DOM 渲染、默认头像、分页和回复去重。发言失败保留草稿；回复目标删除时刷新讨论并清除目标。
- 原生脚本及 Emby AMD 插件注册加载评论组件。普通详情监听 itemshow；直接打开详情和详情弹窗通过 viewshow 与 getItem 补齐。使用 Emby currentResumeSignal 和 pending metadata view 取消离开页面后的元数据请求。
- 本人删除、管理员单条／整条删除、禁言时长、解除禁言与管理记录均使用 v1 接口，最终权限仍由服务端确认。

## 已验证

- Node API／注册测试 8 项通过：可信路由、拒绝向其他服务器发送凭证、Item 头、游标、网络重试 UUID、账号／Item 取消、429、头像路径、Unicode 字数以及 HTTP 环境的 UUID 生成。
- 真实 Chromium 交互 fixture 通过 36 次请求，覆盖普通详情、无 itemshow 的直接／弹窗详情、旧元数据取消、作品／单集切换、纯文本显示、分页去重、发送重试、删除回复目标、409 刷新、禁言列表与审计。使用程序内 QtWebEngine 执行同一 fixture 也通过。
- Windows 完整 CTest **56/56 通过，76.90 秒**。包含实际私有 TensorRT 帧图、EOF、播放器、安装／下载、WebEngine 和新评论区测试。
- 生产 HTTP18443 健康检查和浏览器 Origin 预检成功。使用本机已有 Emby 会话验证身份、用户可见媒体、话题解析和评论分页，未写入测试评论，未增删测试账号。该账号头像为空，实际头像字节尚未由这项生产检查覆盖。
- 独立代码审查报告的弹窗入口、删除后回复目标和延迟元数据取消问题均有失败复现及通过回归；复核无剩余重要发现。

RIFE 完整测试需配置一致的 RIFE_TEST_RUNTIME、RIFE_TEST_IMPLEMENTATION=2，以及匹配的 256×128／240×112 engine path 和 stream prepared fixture。最初使用另一源码目录的默认 smoke-engine 造成测试配置失败；改为同一 v3 运行库的已准备引擎后完整套件通过，没有修改补帧产品代码以绕过测试。

Windows 和 Mac 的补帧性能范围沿用 [RIFE 报告](2026-09-30-windows-rife.md)，本次没有重复三模型 10 分钟性能长测。Windows 高帧率和原生 4K 的实验限制在 README 与更新记录中明确保留。干净系统硬件验收没有因本次功能集成而被标为完成。

## 发布

VERSION 更新为 2.3.0，README 和 CHANGELOG 已重写。发布包应由最终同一提交构建，附 SHA256 和来源清单。Mac 构建工作流增加可选 Apple Silicon 单架构入口；默认多架构调用保持原配置。最终产物与发布状态以 GitHub v2.3.0 发布附件和发行清单为准。

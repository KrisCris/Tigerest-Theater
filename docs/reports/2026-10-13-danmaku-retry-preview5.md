## 行为

- 桌面内置弹幕 API 连接超时 5 秒、单次总超时 20 秒；共享查询和手动绑定请求保留 35 秒总超时。
- 普通弹幕读取和匿名共享查询遇到 curl 6/7/18/28/52/55/56 或 HTTP 408/502/503/504，等待 1 秒后最多重试一次。
- 终止类 4xx 优先于同时出现的 curl 超时或短读，避免对已经返回的权限错误重试。空的成功响应、异常格式的成功响应、证书错误和超大响应不自动重试。
- 429 不自动重试；内置 NAS 两个入口共享 Retry-After 冷却，退避期间收到其他请求的限流也会阻止重试。
- 手动绑定写入只提交一次；失败时按原流程读取已选弹幕，不将失败的写入误报为已保存。
- 换集、手动选源和切换账号取消在途请求及退避定时器，清理加载计数，旧响应不能覆盖新选择。
- 错误日志只记录请求类型、HTTP 状态、curl 退出码和尝试次数，不记录正文、凭据或完整 URL。

自动重试适用于桌面弹幕 API 下载和共享查询；不据此声称 Android 或所有第三方网站来源都已使用同一策略。此修改不能为真正空源生成弹幕，也不能识别被上游包装成 HTTP 200 空数组的错误。

# V2.3.1 设置与界面修复

用户在 V2.3 发布后提出扩展按钮、头像浏览、选集拖动和界面问题，并要求将 MPV 设置整合到 Emby 设置页。本次延续已授权的正式版发布，用新补丁版本保留原发布包和标签。

1. 复现并区分版本兼容门槛与 Qt 动态文件选择器部署遗漏；补充真实发行目录及完整包 GUI 回归。
2. 固定目录显式批准现有封存扩展的兼容应用版本，不改变包内容、哈希、ABI 和清单校验。
3. 用 Emby 插件路由注册客户端设置项，复用原生设置渲染和存储；在导航离开时释放状态信号和计时器。
4. 收敛卡片焦点反馈到键盘可见焦点；优化封面、选集按钮和间距、滚动条及 Windows 原生深色标题栏。
5. 补充 README 导入步骤与排查，运行完整单元、原生和打包 GUI 测试，实际 Emby 路由验收不修改账号或评论。
6. 审查后提交并构建同一源版本的 Windows 与 Mac 正式包，发布 v2.3.1 及校验清单。

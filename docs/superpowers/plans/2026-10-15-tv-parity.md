# TV parity implementation plan

**Goal:** Restore Tigerest's established experience on Apple TV and remove Mac/iPad15 installation gates without claiming old-system support.
**Architecture:** Native SwiftUI TV pages reuse original home/community contracts and AppleCore; a host protocol allows the same iPad danmaku repository/renderer to run on TV. Installation retargeting is independent of TV code.
**Tech stack:** tvOS26+, Xcode27, SwiftUI/UIKit, pinned MPVKit; existing release2.7.0 binaries.
**Spec:** docs/superpowers/specs/2026-10-15-tv-parity.md
**Authorization:** User explicitly requested these changes, upload replacement attachments, and clarified install-only semantics. Continue in current isolated TV branch; preserve user profiles.

## Constraints / review focus
- Never send arbitrary Emby tokens to community/danmaku providers; capability trust and origin checks required.
- Cancel stale media/account requests; final player exit must preserve resume/progress.
- Home must group episodes into works and preserve original library/favorites/recent semantics.
- Bound input/response/cache sizes; retain request IDs on uncertain comment writes; test mutations only with fixtures.
- Differentiate simulator/fixture tests, physical playback and untested old-system runtime. Do not infer performance or HDR from settings alone.

后端同步改动及验收范围：

1. `POST /community/v1/reports` 的 `description` 校验改为 **trim 后 3–2000 个 Unicode 字符**。如果请求 schema 和业务校验都限制了最低长度，两处都应改为 3；不要按 UTF-8 字节或 UTF-16 码元计数。
2. 对应验证错误提示和 `community-api.md` 中的最低长度改为 3 字。
3. 验证“太短”（2 字）返回原有 `INVALID_REQUEST`；“没弹幕”（3 字）、三枚 emoji 及带首尾空白的 3 字说明可以提交；2000 字仍可以提交，2001 字仍拒绝。继续按 trim 后的实际说明进行幂等比较。

客户端直接提交用户输入的真实文本，不补空格、不扩写说明。Windows 的全部 65 项检查通过；生产 3 字提交、平台字段与日志附件已按本页所述单独验证。

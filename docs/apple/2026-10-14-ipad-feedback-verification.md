# iPad 界面反馈、弹幕 PC 对齐与原生 RIFE

范围：继续已批准的 iPad 移植，Xcode 27 beta、最低 iPadOS 26、Personal Team。此记录不表示整个平台移植或 tvOS 已完成。

## 本轮变更

- 首页四张本地媒体库卡片图片：统一资源根目录和文件路径的标准化规则，修复 iOS `/private/var` 路径判断不一致。
- iPad 转场：采用全分辨率 DOM 场景，由 WebKit 合成毛玻璃。避开 240 px 小图放大和不可靠的 OffscreenCanvas 模糊；缓存绑定页面、视口和变更代次，独立飞行的海报从背景副本隐藏。iPad 基础模糊为 5 px；桌面仍使用原有路径。
- 锁定：提示 3 秒后隐藏（包括暂停时）；轻点画面唤回，长按 0.6 秒解锁，按住期间不触发隐藏。
- 画质：三套 Mac shader 预设迁入主设置 `mpv.shaderPreset`，旧选择一次性迁移；主设置改选或重置预设会清除导入覆盖，主设置内可导入着色器和查看诊断。播放器流码率菜单命名为“码率”。
- 弹幕：恢复启用时自动匹配、可见加载状态、手动搜索/选集、导入、来源开关/偏移；布局预先分配轨道，避免旧弹幕离场时现有弹幕跳行，支持固定/滚动、透明度、描边。文字缓存为图层，由屏幕刷新驱动移动，不依赖 10 Hz 播放器状态发布。

## 弹幕规则的依据和边界

直接对照仓库 PC 版 `resources/mpv/plugins/uosc_danmaku/apis/dandanplay.lua`、`modules/mapping.lua`、`modules/http.lua`、`modules/menu.lua` 与 `modules/utils.lua`：

1. 优先查询专属服务共享映射；无匹配/服务异常再查同一媒体历史来源、文件哈希或作品信息。历史 API 来源重新获取弹幕，缓存内容作为离线回退。
2. Emby 在线视频直接用元数据匹配；仅本地文件计算前 16 MiB MD5。匹配不跨集推算 episode ID。
3. 自动匹配保留接口身份、作品相似度、明确季数、正片集数和集名优先规则。同分候选保留歧义，不擅自选择。相似度的 Lua 边界行为也纳入对照。
4. 手动搜索按用户配置顺序汇总多个接口，最多同时请求 5 个，重复作品 ID 保留首个来源；支持逗号列表与 `|` / `#` 备注。专属内外网地址跟随当前 Emby 连接，第三方地址保持独立。
5. 手动共享纠正先尝试保存；缺少授权/写入失败时直接加载所选集数并说明共享未保存。429 遵守 Retry-After，专属内外网共享冷却，禁止继续 GET 绕过限流。手动写入不重试；瞬时读取故障最多 1 秒后重试一次。
6. 换媒体、账户授权变化或手动新选择后，旧异步结果不得覆盖当前选择。选集同时绑定作品、接口与当前播放代次；加载新作品时清空旧集数并禁用重复操作。
7. 官方 Dandan 请求沿用 PC 的 AppId、时间戳与路径签名（不含查询串）；测试实际运行 PC Lua，只保存请求头摘要、不记录解密值。特别保留其 `table_to_zero_indexed` 的实际密钥转换结果。
8. 支持 PC 的 `danmuku` 替代响应格式及默认备用网关的 XML；保持 PC 转换中的位置、颜色、时间舍入规则。
9. 手动 `名称|分类` 搜索沿用 PC `extra.lua`：非中文名称先通过 TMDB 查询中文名；聚合搜索按站点显示结果，优先搜索缓存集数，再取 episodesv2，最后按 200 集分批查询 detail。电影直接使用播放页。外部弹幕跳过官方 `.net` 接口，最多并发三个来源并采用最快成功结果，耗尽后走默认备用网关。

本轮对齐 Dandan/NAS 搜索、自动匹配、共享纠正，以及 `关键词|分类` 搜索入口。各视频网站独立抓取器、PC 脚本自定义 Cookie/代理/TMDB 与备用网关参数编辑仍是剩余移植项；当前聚合搜索使用仓库 PC 默认配置。不能把受控夹具通过表述成所有线上站点已经验证。

## 弹幕低帧率的真机复现与修复

用户报告弹幕帧数很低后，使用同一 M5 iPad、同一 30 fps 本地视频、1200 条受控弹幕测量：旧 SwiftUI Canvas 实际绘制/位置更新约 10.000 fps，95% 帧间隔 100.16 ms。虽然外层声明了 TimelineView，绘制闭包不依赖其时间值，更新仍被播放器的 100 ms 状态发布限制。

改为 CADisplayLink + Core Animation 图层：文字、颜色、描边和阴影只在首次显示时栅格化，并缓存至最多 32 MiB / 256 项；每帧仅更新可见图层位置。屏幕范围内稳定分配弹幕轨道。导入的换行文本在渲染时合为一行，保留全部文字，避免一行位图截断内容。

独立显示时钟平滑插值播放器的粗采样，小幅误差逐渐校正；暂停/缓冲停止运动，跳转在 mpv PLAYBACK_RESTART 后用实际位置重置，避免提前消耗代次。测试验证了 120 Hz 显示、10 Hz 采样、24 fps 时间量化、暂停/恢复和跳转。原回归用例先失败，修复后通过。

最终真机夹具记录：6 秒内 720 次绘制回调，绘制及位置更新 119.998 fps，95% 帧间隔 8.406 ms；暂停冻结、±300 ms 小幅跳转对齐通过；2× 播放下 1 秒前进约 2.063 秒。此值是应用层渲染/移动节奏，不是所有生产视频与 RIFE 同时启用时的合成器帧率保证。

## RIFE 接入

iOS MPVKit 没有 VapourSynth。新增 `tigerest-rife` 原生视频滤镜，把 Mac 的 `RifeEngine`、`RifeMetalWarp`、`RifeCoarseMetal` 直接接到 mpv 的时间戳队列，继续使用现有音频、字幕和 shader 渲染链路。

当前限制：RIFE 4.25 lite / split-coarse-metal，1920×1080、BT.709 SDR、23–30 fps，固定 2×；默认关闭，主设置“视频 → AI 补帧（RIFE）”开启，重新打开视频生效。不支持的分辨率/色彩/隔行片源原帧通过。不能宣称 HDR、杜比视界、4K 或所有 iPad 已支持补帧。

VideoToolbox 帧先下载，再转换为全范围 GBR float；按 RGB 顺序进入模型，输出重新交给 mpv。相邻帧缓存有代次，跳转和不连续时间戳清理缓存；EOF 先输出待发送原帧。修复了硬件帧判断误用底层 NV12 描述，以及 `mp_image_setrefp` 重复引用导致的帧泄漏。下载池与浮点池分开，避免每帧重分配。

此适配使用私有 mpv filter ABI，必须固定 MPVKit `d9194243bdc68b87d8989376ab52aee7da6c8e0b` 和 mpv `41f6a645068483470267271e1d09966ca3b9f413`。依赖升级必须重新核对并运行真机播放探针，不能只改版本号。

## 构建与复现

```sh
# mpv-source 必须是上述完整、干净的固定提交；model 为已校验的 Mac 编译模型目录。
```

## 01:19 反馈：字形、实体键盘和《青之箱》S1E1

- **字形根因**：在 M5 iPad 上对比同一 UIFont / 字号的四种绘制方式。`NSAttributedString.strokeWidth` 同时描边填充会把 CJK 字形内部重叠轮廓也描黑，复现截图横裂；去掉描边或先绘制黑色字形轮廓再填充时正常。改变 renderer 色彩范围无效。生产改为缓存完整字形轮廓与单次填充，保留字号、颜色、透明度、阴影和外缘留白。真机像素回归：16,939 个不透明填充内部像素中受损 0。新方案同一 1200 条夹具约 119.992 fps、p95 8.798 ms，暂停、±300 ms 跳转与 2× 时间推进通过；仍是应用层回调/位置更新测量。
- **空格根因**：原快捷键挂在条件显示的暂停按钮上，OSD 隐藏就卸载。底层 WebView 仍有键盘焦点。新增随播放器存活的响应器，优先消费无修饰空格；使用即时核心暂停状态切换，不重载媒体；锁定时只唤回提示，弹幕/教程/文件弹窗期间让出响应。UI 回归先复现失败，修复后通过，进一步验证输入 `Blue Box`、关闭弹窗恢复、锁定及单/双击，3/3 通过。测试使用系统实体按键注入，未宣称已经人工操作真实妙控键盘。
- **匹配根因**：匿名生产搜索“青之箱”返回第一季主标题“蓝箱”（18278）和“青之箱 第二季”（19249）。第一季详情的 `titles` 明确包含“青之箱”“青春之箱”“Blue Box”；S1E1 为 182780001 / 第1话 千夏前辈。原 PC Lua 与 Swift 都在读取详情前仅用主标题过滤，遗漏同一作品别名。两端同步改为先用主标题检查类型和季数，再从该作品详情取权威别名评分；只有作品评分通过，集名或集号才可供选择。跨季别名不能绕过主标题限制，同分不同作品仍须手动确认，不硬编码作品名称。
- **诊断边界**：之前应用日志只在内存中保留 10 分钟，重启后无法追溯当时匹配记录。本次依据用户确认的 S1E1 和生产 API 返回复现，增加匹配步骤/状态的脱敏诊断；不把重建过程称为已读取旧日志。
- **验证**：38 项 Core；13 个实际 PC Lua/Swift 匹配对照和两个请求头摘要；真机 20 项原生仓库/隔离网络流程（含第一季别名、单次详情请求、不读取第二季）；桌面 libmpv 中 88 项确定性 Lua 运行流程通过。原弱标题测试改为读取详情别名但仍禁止仅凭集名/集号选择；跨季禁止请求不变。夹具不向生产服务写入共享纠正。

- **真机在线发现并修复的第二个漏项**：原 Info.plist 同时设置全局任意加载和 Web/局域网细粒度例外。iPadOS 会忽略前者，原生 URLSession 访问默认 HTTP NAS 被 ATS 拦截（直连 -1022，仓库搜索汇总后表现为 -1011）。保留既有全局配置，单独对 `nas.tigerest.top` 添加 HTTP 例外，不扩展到子域或其他主机。依据 [Apple ATS 版本交互说明](https://developer.apple.com/documentation/bundleresources/information-property-list/nsapptransportsecurity/nsallowsarbitraryloads)。
- **真机生产读取**：新增域例外后，在隔离配置内实际 GET 搜索、详情和弹幕成功；“青之箱” S1E1 唯一解析为 `182780001` 并加载 **5,863 条**评论。该验证使用真实 NAS 响应，不使用网络夹具，不读取用户登录资料，不提交共享纠正。完整自动流程另由 20 项原生仓库夹具验证，用户现有历史/共享映射仍可优先命中。

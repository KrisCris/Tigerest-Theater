# 公共评论、账号与头像

2.6.0 可以让不同 Emby 服务器的用户在同一作品下交流。进入电影、剧集、季或单集详情，评论区通常位于演职人员上方。

## 先确定使用哪种身份

| 当前连接 | 查看和发送评论 | 私人报错与管理 |
| --- | --- | --- |
| 已登录大河 Emby | 直接使用当前 Emby 身份，无需另注册 | 保留原有入口与权限 |
| 已登录自建 Emby，但未登录评论账号 | 显示「注册或登录评论账号后查看评论」 | 不提供大河私人入口 |
| 自建 Emby + 已登录独立评论账号 | 可以参与可匹配作品的公共讨论 | 不因此获得大河私人权限 |

先登录 Emby，再使用评论区。自建用户在没有有效评论登录时，评论列表、回复预览和作者头像不会向当前页面展示。

## 自建用户注册

1. 在作品详情评论区点击「评论账号」；也可以从顶栏「消息」中进入。
2. 在「公共评论账号」窗口点击「注册新账号」。
3. 填写用户名、显示名称和密码。
4. 点击「注册并登录」，完成后返回详情页。
5. 已有评论账号时，直接使用用户名和密码登录，无需再注册。

字段规则：

| 字段 | 规则 |
| --- | --- |
| 用户名 | 3–32 位，以字母开头，可含数字、下划线、英文点和连字符 |
| 显示名称 | 1–60 个字符，作为公开发言名称 |
| 密码 | 以页面旁显示的范围为准；新服务 8–128，旧服务 12–128 |

密码允许字母、数字、符号、中文、emoji 和普通空格；不能包含换行等控制字符。客户端按 Unicode 码点计数，组合表情可能由多个码点组成。密码不会被自动去掉首尾空格，也没有必须混合大小写或数字的额外要求。

如果没有「注册新账号」按钮，可能是服务暂时关闭注册；已有账号仍可按服务状态登录。若用户名被占用，请换一个用户名。

## 修改密码与退出

已登录后打开「评论账号」，填写「当前密码」和「新密码」，点击「修改密码」。新密码采用当前页面显示的规则，修改成功后需要重新登录，其他设备的评论登录也会失效。

「退出评论账号」只退出独立公共评论身份；重新登录后才能查看和发送公共评论。大河账号使用 Emby 管理密码，评论账号窗口会显示“已使用大河 Emby 账号登录公共评论”。

Windows 使用系统凭据管理器，Mac 使用 Keychain，Android 使用 Keystore 加密保存评论登录。如果安全存储不可用，窗口会明确提示本次登录只在当前运行期间有效；下次打开可能需要重新登录。

## 选择讨论范围

详情页只有一个「评论区」，无需选择公共或本服频道。客户端按当前账号自动连接对应服务；大河用户继续看到原话题中的公告、评论和回复，可匹配作品与其他服务器用户共享讨论。发言前确认输入框上方的作品或单集对象。

- 电影、整部剧集和季详情：显示「作品评论」。
- 单集详情：默认「本集评论」，可切换到「作品评论」。
- 公共作品评论：根据可靠的 TMDB 标识关联同一电影或剧集。
- 公共单集评论：还需要明确的播出季集编号；特殊篇可使用季 0，但仍要有可靠元数据。

缺少 TMDB、集序不明确、DVD 集序、合并集或身份冲突时，大河用户仍可在原有话题中交流，是否共享由服务端的媒体匹配结果决定。自建用户会看到无法关联公共讨论的说明，应先由自己的服务器维护者检查媒体元数据，避免把不相关的作品硬合并。

## 发言、回复和删除

1. 确认「作品评论／本集评论」。
2. 输入纯文字内容，可换行，最多 2000 字。
3. 点击「发表评论」。回复别人时先点击目标内容的回复入口，确认输入框上方显示的回复对象。
4. 需要退出回复状态时点击「取消回复」。
5. 使用「上一页」「下一页」浏览；每页按 10 条主评论计数，回复跟随主评论。

自己的内容可以删除。主评论被删除后，已有回复可能继续保留，并显示删除占位。大河账号拥有对应管理员权限时，评论区继续提供管理删除、禁言、解除禁言和管理记录；独立评论账号不获得这些权限。

网络失败会保留当前草稿，使用同一次发送标识重试以避免重复。出现限流提示时按页面等待时间操作。离开详情、退出或切换账号会清理当前草稿；不要把评论输入框当作长期笔记保存。

## 头像怎样更新

**大河用户：** 在自己的 Emby 中更换头像，之后发表主评论或回复。服务端检查变化并同步；首次返回可能还是旧图或默认图，稍后刷新评论即可。

**自建用户：**

1. 在当前 Emby 账号中设置本人头像。
2. 使用已登录的独立评论账号发评论或回复。
3. 客户端先确认当前 Emby 的头像状态，生成用于同步的小尺寸静态 PNG。
4. 评论发送成功后，只有服务端需要新图时才上传。
5. 同步完成后，当前界面的头像刷新；历史评论、回复和消息也使用这个作者的最新头像。

头像来源是当前 Emby 的本人资料。客户端上传处理后的头像图片与校验信息，中央服务不需要自建 Emby 的登录凭据或头像网址。

删除 Emby 头像后，下次发言确认“确实没有头像”会清除旧图；网络中断、读取失败或图片解码失败不会被当成删除，原头像会保留。

## 头像失败与评论失败分开处理

如果已经看到评论发送成功，同时出现头像同步失败，请使用「重试头像同步」。无需再点一次发表评论，也无需把相同文字重新粘贴发送。

多设备同时换头像时，旧上传可能被判为过期；客户端会刷新资料并放弃旧任务。下一次发言再检查当前头像。频率限制只按提示等待，不需要连续重试。

新头像功能取决于服务端能力。连接旧服务时客户端保持旧协议；页面显示默认或旧头像不代表正文没有成功发送。
